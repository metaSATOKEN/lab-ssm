# From a figure or table to its source

Sources for the tables and figures in [LAB](../LAB.md) ([PDF](../LAB.pdf)). Section and figure numbers below follow the manuscript, not the order of filenames. Follow the phase link for the collecting code and the JSON link for the saved measurement. All values can be inspected without running a model.
